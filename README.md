# 欢迎来到AQPA镜像站

APQA镜像站主要收录关于Proxmox的资料

## 目录说明

- Proxmox  

  这里收录的是pbs和pve的arm64源。该源托管在ocacle 首尔的arm vps上面。使用alist本地挂载到proxmox 路径。	

  当配置为源路径时，Nginx会根据（debian apt)user-agent自动反向到软件repo目录，实现直链下载。

- vGPU

  这里收录的是Nvidia vGPU基于KVM的驱动，包括已经处理过的vGPU_unlock驱动。还有免费的授权和lic服务器相关文件。

  备用访问地址：https://1drv.ms/f/s!Au56ONQentYvpx79UUwmn4ngav5t?e=63j0T6

- KVM

  包括一些KVM的驱动，管理工具等等

- Proxmox-edge

  是和Proxmox 直接相关的一些东西，如ISO，系统备份包，相关脚本等等。

  备用访问地址：https://1drv.ms/f/s!Au56ONQentYvpx79UUwmn4ngav5t?e=63j0T6

- foxi

  博客以前的旧链接。会被逐步删除，相应的文件，会同步到上面的文件夹
